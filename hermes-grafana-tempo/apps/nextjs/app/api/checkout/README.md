# 🛒 /api/checkout

`POST /api/checkout` totals the cart and creates an order. An empty body or `{}` throws an unhandled
`TypeError` (planted). See [`route.ts`](route.ts) and the [app README](../../../README.md#-planted-issues-and-how-to-find-them-in-tempo).
